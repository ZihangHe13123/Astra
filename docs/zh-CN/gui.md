# 桌面 GUI 预览版

桌面端支持 [可稍后回答的可选提问](../async-user-questions.md)、[PDF/Office 本地预览](../desktop-document-preview.md)，以及上下文面板中的请求执行时间线。时间线区分服务商用量与客户端估算；未采集的数据保持空缺。桌面后端默认记录有界的脱敏指标，可用 `ASTRA_PROFILE_QUERY=0` 关闭；记录不包含完整提示词。

窗口关闭、应用菜单退出、Cmd+Q 和托盘退出共用任务检查，尚未确认的消息提交也会受到保护。独立本地安装包和离线更新、回滚的构建说明见 [桌面分发](../desktop-distribution.md)；正式签名、公证和跨平台实机验收单独记录。

[首页](../../README.zh-CN.md) · [文档导航](README.md) · [English](../gui.md)

Astra 的源码桌面预览版使用 Electron 和现有 Python 后端，支持对话、模型连接、独立后台会话、
工具审批、追问、文件改动与搜索式命令面板。完整 TUI 功能对等仍是后续目标；
[设计与当前覆盖情况](../design/gui.md)记录了剩余工作。

## 安装和启动

本地独立应用打包及恢复更新见[桌面发行说明](../desktop-distribution.md)。独立包自带 Python 和 Electron；
下面介绍源码安装方式。

需要完整源码仓库、Python 3.11+、Git，以及 **Node.js 22.19+（含 npm）**。
已经注册 `astra` 命令的安装可直接运行：

```text
astra setup --gui
astra --gui
```

尚未注册命令时，在安装目录运行：

| 平台 | 安装 | 启动 |
| --- | --- | --- |
| macOS | `./astra.sh setup --gui --install-command` | `astra --gui` |
| Windows CMD / PowerShell | `.\astra.bat setup --gui --install-command` | `astra --gui` |

安装前先退出正在运行的 Astra 会话。`--install-command` 会将 `astra` 注册到用户 PATH；
完成后打开新终端，在准备使用的项目目录运行 `astra --gui` 即可。
不注册全局命令也可以在源码目录用 `./astra.sh --gui` 或 `.\astra.bat --gui` 启动。

直接运行 `astra` 仍打开 Ink。只安装终端版不会下载 Electron；`setup --gui` 安装锁定的桌面组件，
并记录组件选择供后续更新使用。尚未提供正式签名的公共安装程序。Linux 桌面使用属于实验范围，原有 Python/TUI 平台支持不变。

窗口打开后启动命令会返回，关闭发起命令的终端不会结束桌面。对同一安装/数据目录再次启动，会聚焦已有窗口。
再次打开桌面会恢复最近活跃会话及未发送草稿，恢复本身不会发起模型请求。
标题栏显示工作区；添加项目会让对应后端在该目录执行工具。

## 连接模型

点击欢迎页的 **连接或选择模型**，或输入框旁的模型按钮。
选择 **ChatGPT / Codex**，点击 **登录 ChatGPT**，打开授权页面完成设备登录；保存连接后再选择可用模型。
API 路线支持输入 Key 或环境变量名，以及可选的服务地址。
账号要求和常见问题见 [ChatGPT 登录指南（英文）](../codex-oauth.md)。

凭证继续使用 Astra 原有认证存储，每台电脑单独连接。推理区域只显示服务端实际返回的内容或摘要，
不会补造模型没有提供的内部思考。

模型列表区分 **未连接**、**已配置**和连接状态待确认。点击缺少凭证的模型会先打开对应连接表单，
不会反复提交缺少 Key 的切换请求。“已配置”表示已有凭证配置，不代表已经通过真实鉴权测试。
切换进度和失败原因显示在 **模型与账号**窗口，失败时保留当前模型；当前模型缺少连接时，
输入框上方也会出现 **连接模型**入口。独立源码目录尚未配置 `.env` 或登录信息时，可从这里完成设置。

## 对话和工具

- **新对话**先回到当前项目的空白草稿；连续点击复用同一草稿，不会在侧栏刷出一排空会话。
  打开模型设置或准备窗口捕获时可能按需启动后端，仅用于配置的后端仍作为草稿保留。
  真正开始对话后，会话拥有独立后端。切换会话时后台工作继续，侧栏圆点提示运行或等待输入。
- 历史会话先只读浏览，点击 **继续此会话**再打开写入者。如果另一个 TUI/GUI 进程正在使用该会话，
  后端会拒绝第二个写入者；先关闭原写入者再继续。在历史预览中打开模型、权限或人格设置也会继续该会话，操作不会落到此前隐藏的会话。Work、Minimal、Bar 保留独立命名空间。
- 文字与普通附件列表按会话保存。发送获得后端接收确认后才清空已提交草稿；接收状态未知时保留草稿，
  应先查看结果再决定是否重发。重新连接不会自动重复模型请求。
- 工具审批和结构化追问直接显示在对话中。运行时输入框为空则发送按钮变为停止；输入新指令可补充或调整方向。
- **执行详情**包含工具/进程、逐回合文件差异、文件/图片、上下文和 Team 状态。
  缺失/淘汰快照与未确认改动分别标明。大文本预览有大小边界，完整文件可用 **系统打开**查看。
- **命令与功能**覆盖当前全部 TUI 根命令，支持可选参数。`/tool N`、`/gallery N` 定位对应记录。
  `/memory`、`/skills`、`/tasks`、`/diagnostics` 等低频功能当前使用兼容表单和既有后端输出，专用管理页仍待完善。

Markdown 图片和文件可从当前工作区及 Astra 产物目录预览。外部文件通过文件选择器明确选取。
原始 HTML 和可执行 URL 不会渲染；这些展示规则不改变模型已经获得的工具权限。

## 可交互卡片

回复里可以嵌入一小块可交互的展示：带滑块的计算器、可以逐步点开的流程、能切换的对比。
模型把它写成语言标记为 `card` 的代码块，内容是一段 HTML 片段，可以自带 `<style>` 和 `<script>`：

````markdown
```card
<h3>复利</h3>
<label>年数 <input id="years" type="range" min="1" max="40" value="20"></label>
<p>1,000 会变成 <strong id="total"></strong></p>
<script>
  const years = document.getElementById("years"), total = document.getElementById("total");
  const show = () => { total.textContent = Math.round(1000 * 1.05 ** years.value).toLocaleString(); };
  years.addEventListener("input", show); show();
</script>
```
````

桌面端在原位运行写完的代码块；代码块还在输出时，或者无法运行时，显示的是源码。**查看源码**
可以在两者之间切换。终端和消息通道把它当普通代码显示，所以回复本身不看卡片也应该讲得通。

卡片能做什么、不能做什么：

- 它运行在自己的隔离框里，接触不到 Astra：没有桥接接口，看不到会话和文件，也没有存储。
  它只收到自己的源码和主题颜色，只汇报自己的高度。
- 它不加载、也连不上任何外部内容。脚本、样式、图片、字体都必须内联（允许 `data:` 图片）；
  网络请求、WebSocket、WebRTC、表单提交、弹窗和页面跳转都会被拒绝。卡片里的链接点不开。
  卡片如果让自己的框跳转到别处，会被停止并改为显示源码。
- 可以通过 CSS 变量 `--bg`、`--panel`、`--soft`、`--hover`、`--line`、`--text`、`--muted`、
  `--accent`、`--on-accent`、`--error` 使用主题颜色，文字、按钮、输入框、表格也有默认样式，
  因此会跟随浅色和深色主题。
- 状态只在它显示在已打开的会话里时保留：滚动到很远的地方、切换到源码、或重新打开会话，
  它都会重新开始。
- 超过 200,000 个字符的代码块只显示源码。

模型不会自己知道有卡片这回事。需要把上面的格式写进一个技能或项目说明里，并说明卡片只用于桌面端。

## 输入框里的指令帮助

输入框默认只占一行，内容变多时自动长高，最多 220 px 后在框内滚动。
在消息开头输入 `/`，会弹出指令菜单：可输入英文指令或中文用途筛选，例如 `/模型`、`/bar`。
方向键选择，Tab、Enter 或点击填入命令；**补全不会执行，按发送或在补全后再次按 Enter 才执行**。
Escape 关闭菜单并保留草稿，Shift+Enter 仍然换行。带附件或多行文字时不弹出菜单。

进入特殊模式后，菜单优先显示当前模式的操作；输入完整前缀可查看子命令：

| 模式 | 继续最近会话 | 新建独立会话 | 查看历史 | 返回通用 |
| --- | --- | --- | --- | --- |
| 酒吧 | `/bar` | `/bar new` | `/bar sessions` | `/bar leave` |
| 极简 | `/minimal` | `/minimal new` | `/minimal sessions` | `/minimal leave` |

在 GUI 中，“查看历史”打开对应模式的会话列表，不创建新会话。新建会保留旧会话。
`/bar sip` 喝一口当前饮品；`/bar output atomic` 整段显示，`/bar output stream` 流式显示。
本机安装的扩展模式会按后端定义显示指令与说明。
切换不同特殊模式前，先用当前模式的 `leave` 或点击 **通用**。
**权限与对话模式 → 查看模式指令**也可打开对应帮助，不覆盖正在编辑的草稿。

## 会话菜单

点击已打开或历史会话旁的 **…**，也可以从 **设置 → 管理会话**搜索并操作会话。

| 操作 | 效果 |
| --- | --- |
| **重命名** | 修改当前 GUI 中的显示名称，底层会话 ID 和文件名不变。 |
| **置顶 / 取消置顶** | 将会话加入置顶区，或从置顶区移除。 |
| **导出 Markdown** | 通过系统保存窗口选择位置，导出完整已保存对话，包括既有工具输出和子代理记录。导出不修改原会话，也不受当前历史分页限制。 |
| **关闭会话后端** | 结束该会话的本地后端，保留已保存历史；应先结束或停止当前工作。之后仍可打开历史继续。 |
| **删除会话** | 确认后删除当前命名空间中的会话历史、关联记录和窗口捕获媒体；模型修改过的项目文件保留。仍有活动任务或被其他写入者占用时不能删除。 |

Work、Minimal、Bar 中同名会话各自独立；菜单只操作选中的命名空间，删除一个不会连带删除其他模式中的同名会话。

安装中的可选本地模式从运行中的后端发现，沿用扩展自己的命令和名称，可从
**权限与对话模式**或**命令与功能**进入。已打开的扩展会话支持显示名称、置顶和关闭后端；
GUI 暂不提供扩展会话的离线历史浏览、导出和删除，请使用扩展自身命令管理这些记录。
公开版不内置私人模式或私人人格。

## 权限与人格

点击输入框旁的审批模式按钮，打开 **权限与对话模式**。明确选择 **按需审批**或 **完全访问**，
并通过对话模式选项进入通用、极简、酒吧或当前安装提供的本地模式。特殊模式之间切换时先返回通用模式。按钮调用现有后端命令，不增加模型工作流或工具额度；
需要用户处理的审批仍在对话内显示。

从 **设置 → 人格设置**选择当前后端提供的人格。模型按钮、会话菜单及这些设置覆盖常用操作，
其余命令和自由参数仍可通过 **命令与功能**执行。

## 窗口捕获与生命周期

GUI 适配器复用现有 [Appshot](appshot.md) broker 和经过校验的捕获协议。
安装原生辅助程序后，使用 `/appshot enable` 启用。捕获加入当前选中会话的草稿，由用户单独发送。
`/appshot pending status` 查询不确定请求，`/appshot pending discard` 丢弃本地附件状态，但不会撤销已经被接收的请求。
窗口捕获连接情况在输入区附近保留一条当前状态。broker 不可用时显示 **窗口捕获暂不可用，不影响对话**及
**检查连接**入口，重试不会把同一提示反复追加到对话历史。这条状态表示捕获可用性，与模型连接状态分开显示。
macOS/Windows 上的 GUI 原生捕获仍需要逐平台验收，协议夹具通过不等于真机权限已经通过。

关闭窗口时，若仍有执行、等待输入、Team 活动或会话提醒，会提供 **后台继续**、**停止并退出**、**返回**。
隐藏后可从托盘重新打开。`/restart` 沿用已有的可见确认协议重启后端。
关闭桌面会结束它拥有的后端；会话 wakeup 仍依赖后端存活，不会变成离线定时服务。

## 更新与诊断

执行 `astra update` 前退出 GUI，包括隐藏在托盘中的实例。桌面运行持有与 TUI 一样的安装租约。
更新会重建已启用的 GUI 组件及共享客户端，生成文件和组件选择纳入安装/更新回滚。

```text
astra doctor --json
astra setup --gui --repair
```

Doctor 单独报告 GUI 组件状态。启动时不会后台安装缺少的软件包；Electron 或构建产物缺失时，
明确运行 setup/repair。如果通过 Git 手动更新源码，更新后运行 `astra setup --gui --repair` 重建桌面资源；
使用 `astra update` 则会自动重建。GUI 偏好保存在当前数据目录的 `gui/` 下，后端日志使用 `AGENT_LOG_DIR`，
脱离终端启动的诊断日志在 `gui/launches/` 下。

## 快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 发送 / 换行 | Enter / Shift+Enter | Enter / Shift+Enter |
| 新对话 | Cmd+N | Ctrl+N |
| 命令面板 | Cmd+K | Ctrl+K |
| 取消当前任务 | Cmd+. | Ctrl+. |
| 工具审批：允许一次 / 本会话允许 / 拒绝 | Cmd+Enter / Cmd+Shift+Enter / Cmd+Delete | Ctrl+Enter / Ctrl+Shift+Enter / Ctrl+Backspace |
| 工具详情 | Cmd+Shift+O | Ctrl+Shift+O |
| 上下文详情 | Cmd+Shift+L | Ctrl+Shift+L |
| 关闭弹窗/详情 | Escape | Escape |

审批快捷键在窗口内任何位置都作用于最早的一条待审批请求。焦点所在的输入框里有文字时，
这几个键照常用于发送和删除，草稿不会被当成答复；有弹窗打开时不生效。请求被滚动到视野外时，
第一次按键只把它滚回来，再按一次才答复。审批卡片不会自己
抢焦点；点击或用 Tab 进入卡片后，Y 或 Enter 允许一次，A 本会话允许，N 或 Escape 拒绝，
和终端里一样。

## 开发检查

先运行一次 `astra setup --gui --extra dev`，之后在源码根目录运行：

```text
npm --prefix ui-core test
npm --prefix ui-tui run build
npm --prefix ui-gui test
npm --prefix ui-gui run build
npm --prefix ui-gui run test:e2e
```

`test:e2e` 使用真实 Python 后端、本地模型夹具和临时数据，不复制账号凭证，不调用付费模型。
截图和结果保存在被忽略的 `output/playwright/gui/`。手动 **Desktop preview** 工作流会在 macOS/Windows 上
构建、运行单元测试和这一端到端夹具。

当前预览版尚未完成完整平台验收、GUI 内真实 ChatGPT 登录、原生捕获竞争、长时间流式/内存压力、
全部读屏与 IME 场景。历史已使用动态测量高度的虚拟列表，最多挂载 100 条消息，支持分页并保留阅读位置。
本地夹具通过不代表设计中的 A01–A16 已全部验收完成。
