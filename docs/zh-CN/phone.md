# 手机随身端

[首页](../../README.md) · [文档](README.md) · [English](../phone.md)

配对的 iPhone 远程使用桌面版自己的界面：同样的会话列表、对话、审批和提问、命令面板、模型、模式、权限（包括完全访问）、文件改动和历史记录，按手机屏幕排版。模型、工具和记忆都留在 Mac；手机是同一个 Astra 的另一块屏幕，在手机上做的操作都作用在 Mac 的后端上。设计见 `specs/phone-companion.md`。

有些操作只在 Mac 前才有意义，在手机上会提示不可用：选择文件或文件夹（附件、项目）、打开或预览文件、窗口捕获、导出会话、配对手机。模型写的卡片和页面在手机上显示源码而不运行，因为在手机上它们会和应用共用同一个来源。主题、草稿等显示设置保存在手机上；会话名称和置顶来自桌面版。

## 设置

1. Mac 和 iPhone 都装 Tailscale，登录同一个 tailnet。在 Tailscale 管理后台打开 MagicDNS 和 HTTPS Certificates。
2. 出门时让 Mac 保持清醒：接上电源，在“系统设置 → 电池 → 选项”里打开接电源时防止自动睡眠。MacBook 合盖会睡，除非接着外接显示器。
3. 在桌面版打开“设置 → 手机”，打开“允许配对的手机连接”。桌面版只监听 `127.0.0.1:8930`（可用 `ASTRA_PHONE_PORT` 改）。
4. 在 Mac 的终端运行一次 `tailscale serve --bg 8930`。之后 Tailscale 用 HTTPS 在这台 Mac 的 tailnet 地址上提供页面，地址会显示在设置里。不要用 Tailscale Funnel，它会把页面放到公网上。
5. 在 iPhone 的 Safari 打开这个地址，点“分享 → 添加到主屏幕”，再从主屏幕打开 Astra。
6. 在 Mac 的设置里点“添加手机”，五分钟内在手机上输入八位配对码。

## 安全

- 不监听任何网络地址：只有 Tailscale 能到达桌面版，也只有你 tailnet 里的设备能到达 Tailscale。
- 每台手机生成自己的签名密钥，手机存储里读不出私钥。Mac 只保存公钥，每次登录都签一次性挑战，没有共用口令。配对码只能用一次，五分钟有效，输错五次就作废。
- 设置里列出已配对的手机。“移除”会立刻断开那台手机，并让它无法再登录，要重新配对。
- 从手机发出的每条消息、命令、审批和对提问的回答都记在 Astra 桌面数据目录的 `phone-audit.jsonl` 里，包括哪台手机、时间和决定；消息正文不保存，只记长度。
- 关掉“允许配对的手机连接”就停止网关。手机能连上的前提是桌面版在运行；托盘图标让它在没有窗口时也保持运行。
